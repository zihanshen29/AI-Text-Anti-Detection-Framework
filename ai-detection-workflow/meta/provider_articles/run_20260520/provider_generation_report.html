模型详评

豆包：87 分

优点：内容覆盖完整，案例和数字密度高；网站端可编辑并稳定下载 Markdown，最适合直接进入后续编辑。补齐 topic_01 后覆盖完整，但该篇保留反斜杠转义和 AI 注记，仍需清理。

问题：Markdown 层级偏少，长文扫描性弱；英文文件有转义痕迹，例如反斜杠加连字符或句点，部分内容带具体数字但未做事实核验。

建议用途：首选：批量生成可编辑 Markdown 初稿、中文政策/产业观察、需要快速进入后续工作流的场景。

Gemini：84 分

优点：结构意识最强，多数文章有清晰二级标题；英文技术和政策主题的章节组织尤其稳定。平台端 Markdown 指令遵从不稳定，导入 Google 文档流程偏慢。

问题：格式输出有波动，部分样本保留占位标题；中文文章有时偏宏观，案例密度低于豆包。

建议用途：首选：需要清晰章节结构的英文技术 brief、政策分析、框架化长文。

文心一言：76 分

优点：样本完整，资料感强，中文可读性稳定；Word 下载适合人工编辑。转 Markdown 后仍有占位标题和格式清理成本。

问题：全部从 Word 转换，Markdown 原生性弱；部分文件保留 topic_xx 占位标题或代码围栏类痕迹。

建议用途：适合：Word 编辑交付、资料型初稿、需要人工在文档里继续修订的场景。

DeepSeek：67 分

优点：段落自然，观点素材可用，部分治理类中文段落有现实感；补齐 topic_06 后样本完整。网站端只能纯文本，缺编辑和导出，格式生产效率最低。

问题：无 H2 或标题层级不足，纯文本后处理成本高；即便文字质量可用，也不适合作为批量 Markdown 生产端。

建议用途：适合：提炼观点素材、生成自然段落、作为二次改写底稿；不建议承担格式交付。
